Abstract

Type-1 diabetes management requires patients to repeatedly choose an insulin bolus dose without ever observing what would have happened under a different choice — real patient records only ever contain the treatment actually given, never the alternative. This project uses simglucose, a differential-equation simulator of Type-1 diabetic patients, to construct genuine counterfactual ground truth by branching the same virtual patient, at the same internal physiological state, forward under multiple candidate doses. Building on this capability, the project is organized around four ideas — counterfactual ground-truth validation, a treatment-effect decomposition head, AlphaFold-style iterative refinement, and counterfactual-specific uncertainty calibration — and first establishes a rigorous six-model baseline ladder (persistence, linear regression, random forest, XGBoost, and LSTM with/without dose conditioning), evaluated identically via patient-stratified 5-fold cross-validation. The dose-conditioned LSTM already achieves the best accuracy and the most consistent performance across patients, and a validated simulator finding — candidate doses differ by only 4.4 mg/dL at 1 hour but by 62.4 mg/dL at 4 hours — motivates the project's core architectural work, currently in progress.

Introduction

Type-1 diabetics depend entirely on injected insulin. Existing CGM forecasting work only predicts what will happen — never what would have happened under a different dose, because a real patient can only ever receive one treatment. This project uses a branchable physiological simulator (simglucose) to make that comparison possible, and validate it against real ground truth.

Methodology

Counterfactual Ground-Truth Validation

Same virtual patient, same internal state, branched into multiple insulin doses — each resulting trajectory is genuinely true. Impossible with real patient data.

Architecture

Treatment-Effect Decomposition Head

Model output = no-intervention baseline (Y0) + dose-induced delta (τ), not a single black-box number.

Architecture

AlphaFold-style Iterative Refinement

Coarse prediction first, then recycle and refine — concentrated on the hardest post-dose response window.

Counterfactual-Specific Calibration

A small ensemble scores uncertainty separately for factual vs. hypothetical predictions.

Results So Far — Baseline Ladder

Six models of increasing complexity, all evaluated on the same 5-fold patient split, so any improvement is real and quantifiable — not traditional ML → LSTM without dose → LSTM with dose.

Two takeaways

Patient physiology genuinely varies — the same subset of patients is hardest to predict across all six models, not a fluke of any one method.

Seeing the dose helps, and helps most on exactly those hard patients — a clean signal that treatment information is worth architecting around.
